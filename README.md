# 오픈소스 기여

## Mixdog

- 모델 전환과 세션 재시도 중 IPC 검증 규칙이 서로 달라 발생하던 오류를 수정하고 회귀 테스트를 추가했습니다. [PR #37](https://github.com/tribgames/mixdog/pull/37)
- 벤치마크 비용의 36%가 실패 관련 실행에 쓰인 것을 확인하고, 에이전트의 진행이 멈춘 상황을 감지하는 방법과 추론 강도를 조절하는 방법을 제안했습니다. [Issue #38](https://github.com/tribgames/mixdog/issues/38)

## ClaudeRipple

- 요청마다 바뀌는 빌링 헤더 때문에 프롬프트 캐시를 재사용할 수 없던 문제를 수정했습니다. [PR #37](https://github.com/PBJ-2/clauderipple/pull/37)
- Linux에서 `systemd` 사용자 서비스로 실행할 수 있도록 하고 모델 선택과 인증서 설정을 개선했습니다. [PR #33](https://github.com/PBJ-2/clauderipple/pull/33) · [PR #34](https://github.com/PBJ-2/clauderipple/pull/34)
- 도구 실행 후 이전 대화 맥락이 사라지는 문제를 수정했습니다. [PR #32](https://github.com/PBJ-2/clauderipple/pull/32)
- 테스트가 실제 사용자 설정을 변경하지 않도록 테스트 환경을 분리했습니다. [PR #30](https://github.com/PBJ-2/clauderipple/pull/30)
- 설치 과정을 개선하고 라우터가 실행 준비를 마쳤는지 확인하는 로직을 수정했습니다. [PR #31](https://github.com/PBJ-2/clauderipple/pull/31)
