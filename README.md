# 현장 업무를 자동화합니다 — 비전공, AI 활용

화학공장 유틸리티 설비 점검과 조선소 현장에서 일해 왔습니다.
코딩을 배우지 않고 **AI와 대화하는 방식**으로, 종이와 엑셀로 돌아가던 일을 **구글시트 + Apps Script** 로 옮기고 있습니다.

## 업무 자동화 포트폴리오

전부 **합성(가상) 데이터**로 만든 재현 가능한 예제입니다 — 회사 자료를 쓰지 않았습니다.

| | 만든 것 | 규모 |
|---|---|---|
| ① | [현장 점검표 자동 집계·주간보고](https://github.com/grapefruit0205/plant-inspection-automation) | 점검 12항목 · 설비 20대 → 기준 초과 자동 판정 · 담당자 메일 · 주간 PDF |
| ② | [실무 서류 자동 생성 세트](https://github.com/grapefruit0205/office-docs-automation) | 점검기록 **5,040행** → 점검대장(`.xlsx`) · 작업계획서·점검결과보고서 **40부**(PDF·DOCX·구글독스) |
| ③ | [생산·품질 대시보드](https://github.com/grapefruit0205/production-quality-dashboard) | 생산일보 **5,475행** → 집계 5탭 · KPI 카드 6 · 차트 6 · 경영진 리포트 PDF |
| ④ | [AI 활용 가이드](https://github.com/grapefruit0205/ai-work-automation-guide) | 어떻게 시켰고 · 어디서 틀렸고 · 무엇을 사람이 결정했는지 |

## 이 저장소들이 보여 주는 것

- **현장을 아는 사람이 만들었습니다** — 임계값(예: 토출압력 7.0 bar), 심각도 상/중/하, 담당 부서(기계/운전/안전), 교대조·계절성 같은 판단이 코드가 아니라 시트의 기준값으로 들어가 있습니다.
- **AI가 만든 코드를 그대로 쓰지 않았습니다** — 실제로 났던 오류 20건 이상을 원인 단위로 고쳤고, 각 저장소 `docs/prompt-log.md` 에 그대로 남겼습니다.
- **검증을 기계로 합니다** — 자가 진단 함수(12항목), 문서 대조(누락 0건), 전후 소요 시간 로그. "됐습니다"가 아니라 숫자로 확인합니다.
- **무료 계정 제약을 전제로 설계했습니다** — 6분 실행 제한(분할·이어쓰기), 일시적 오류(자동 재시도), 엑셀 호환 함수만 사용.

> 개인정보·회사 자료는 쓰지 않습니다. 알림 메일 주소 같은 값은 저장소가 아니라 시트의 `설정` 탭에 사용자가 직접 넣습니다.
